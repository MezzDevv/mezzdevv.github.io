My pipeline

I use AI in my work.

I built my own pipeline for it: a team of AI agents with one job each. One scripts, one builds UI in each game's own style, one makes VFX, one models in Blender and brings the models into Studio, and one picks the sound. Another that generates brand-new sound effects is in the works.

They work directly inside Roblox Studio and follow rules I wrote from the games I've shipped, and a panel of AI reviewers checks the Luau before it reaches me. I pick what gets built, and I read, test and fix everything before it goes out.

  1. Idea
  2. Briefwhat the game is, what done means
  3. Build crewscripting, UI, VFX, 3D, sound
  4. My review in Studioread, playtest, fix
  5. Ship

After each game ships, I write down what worked so the next one starts from there.

It's built to take a game from idea to release in about a week. Chop a Verity went from idea to release in 3 days. Every build follows the same rules, and nothing ships until I've read it and played it myself.

Is it all AI?

No. AI writes the first draft and I decide what stays. I've been scripting in Luau and building in Studio since early 2025, before I started using AI, and I still write and fix code by hand when the tools get it wrong.
